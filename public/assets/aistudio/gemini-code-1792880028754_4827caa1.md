قم بإنشاء تطبيق ويب متكامل واحترافي من صفحة واحدة (Single Page Application) كلوحة تحكم وسكانر لتحليل وتداول العملات الرقمية باسم:
"SOSSKA1 Institutional Screener & Opportunity Lab"

المواصفات التقنية والتصميمية المطلوبة:
1. التصميم وواجهة المستخدم (UI/UX):
- التصميم داكن بالكامل (Dark Futuristic Cyberpunk / Bloomberg Terminal style) بألوان عالية التباين:
  * الخلفية: أسود داكن مائل للكحلي (#0b1020 و #121a2b).
  * درجات اللون: الأخضر الزمردي للإشارات الصاعدة (#31d0a0)، والأحمر الوردي للهبوط (#ff7085)، والأزرق المضيء للمؤسسات (#7da8ff)، والكهرماني للتنبيهات (#ffc66d).
- واجهة متجاوبة بالكامل (Responsive) تعمل بسلاسة على شاشات الحاسوب والموبايل، مع دعم الاتجاه العربي (RTL) والأرقام والرموز اللاتينية الواضحة (Monospace fonts للأسعار).
- تقسيم الشاشة إلى لوحة تحكم ذكية (Dashboard Grid) تحتوي على الأقسام الآتية:

2. الأقسام والمكونات الأساسية:

أ) شريط الحالة العلوي (Market Pulse Header):
- مؤشر حالة ماكرو البيتكوين (BTC Macro Trend): عرض حالة BTC على فريم 15m/1h (فوق أو أسفل EMA 100) مع إضاءة خضراء (Bullish Regime) أو حمراء (Bearish Regime).
- حالة الاتصال (Live WebSocket / Binance Public REST API simulation status).
- توقيت القاهرة اللحظي وساعة إغلاق شمعة الـ 15 دقيقة.

ب) جدول مراقبة الفريمات المتعددة (MTF Trend Matrix - محاكاة Multi-Timeframe):
- جدول يراقب قائمة العملات الأساسية: ['BTC/USDT', 'SOL/USDT', 'SUI/USDT', 'HBAR/USDT', 'AVAX/USDT'].
- يوضح اتجاه كل عملة عبر 3 فريمات: (15m, 1h, 4h) اعتماداً على تموضع السعر بالنسبة لـ EMA 50 (صاعد 🟢 / هابط 🔴).

ج) شريط هيمنة السيولة المؤسسية (MCDX+ Smart Money Tracker):
- مقياس بصري بياني (Bar/Gauge) يوضح نسبة سيطرة صانع السوق/المؤسسات (Banker / Institutional Flow باللون الأحمر/المضيء) مقابل سيطرة المتداولين الأفراد (Retail Volume باللون الأخضر) بناءً على تدفق الفوليوم المرجح بحركة الشموع.

د) مؤشر مناطق التشبع المؤسسي (LAL3 Gemini / MFI Oscillator):
- مقياس لتدفق السيولة الحقيقي (Money Flow Index) لتحديد مناطق التشبع المؤسسي بدقة بدلاً من RSI التقليدي:
  * تشبع بيعي حقيقي / تجميع حيتان: MFI < 25 (فرصة شراء قوية).
  * تشبع شرائي / تصريف مؤسسات: MFI > 75 (تحذير جني أرباح).

هـ) مختبر الفرص وحاسبة إدارة المخاطر اللحظية (SOSSKA1 Opportunity Calculator):
- نموذج إدخال سريع لحساب الصفقات فور ظهور الإشارة:
  * المدخلات: سعر الدخول (Entry Price)، قيمة ATR(14)، رأس المال (USDT)، ونسبة المخاطرة (Risk %).
  * المخرجات المحسوبة تلقائياً:
    - صفقات الشراء (Long): SL = Entry - (1.8 * ATR), TP1 = Entry + (2.5 * ATR), TP2 = Entry + (5.0 * ATR).
    - صفقات البيع (Short): SL = Entry + (1.8 * ATR), TP1 = Entry - (2.5 * ATR), TP2 = Entry - (5.0 * ATR).
    - حجم المركز الدقيق (Position Size) ومبلغ المخاطرة بالدولار.
  * زر سريع لنسخ تفاصيل الصفقة كرسالة منسقة لتليجرام.

و) سجل التنبيهات الحية (Signals Feed):
- قسم يعرض الإشارات المقتنصة تلقائياً مع تفاصيل الدخول والأهداف ونسبة الفوليوم المؤسسي (Volume Burst Multiplier).

3. الأداء والتقنيات البرمجية:
- كود مكتوب بلغة HTML5 نظيفة مع CSS مدمج حديث (CSS Variables, Flexbox, Grid) وجافاسكريبت نقي (Vanilla JS) أو React بدون مكتبات ثقيلة لتوفير استهلاك الرام والمعالج.
- دعم جلب الأسعار المباشرة من Binance Public REST API (`https://api.binance.com/api/v3/ticker/24hr`) لتحديث الأسعار في الجدول تلقائياً كل 10 ثوانٍ مع إضافة خيار التحديث اليدوي.
- حفظ التجارب والإعدادات محلياً في المتصفح باستخدام `localStorage`.

قدم الكود كاملاً في ملف واحد جاهز للتشغيل مباشرة بالمتصفح دون أي نقص.
